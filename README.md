# Keccak-Verilog

Verilog implementation of the Keccak-f[1600] permutation used in SHA-3.

## Features
- Theta step
- Rho step
- Pi step
- Chi step
- Iota step
- Round function
- Top-level permutation module

## Directory Structure
rtl/
tb/

## Tools Used
- Verilog HDL
- Icarus Verilog

## Future Work
- Testbench verification
- SHA3-256 wrapper
